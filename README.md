# FORI Studio storefront

A zero-cost static storefront for small, fixed-scope digital services. The site is designed for GitHub Pages and sends quote requests to this repository's public issue tracker.

## Offers

- Data cleanup from 5 USDC
- Python or JavaScript utilities from 10 USDC
- Sourced research briefs from 7 USDC
- Landing-page copy from 5 USDC
- Three-image packs from 8 USDC
- Small API or workflow automations from 20 USDC

Customers receive a written scope and quote before payment. Payment is accepted in USDC on Base only after quote acceptance. Secrets, private customer records, spam, fake engagement, security exploitation, and deceptive work are not accepted.

## Local preview

Open `index.html` directly, or run a static HTTP server in this directory.
